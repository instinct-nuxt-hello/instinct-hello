# instinct-hello

Minimal Nuxt 3 app: a button labeled "click me" that reveals "Hello ! Im Instinct and Im Awesome!".

Live site: https://instinct-hello.surge.sh (statically generated with `nuxi generate`, hosted on surge.sh free tier).

## Run locally

```
npm install
npm run dev
```

## Generate static site

```
npm run generate
# output in .output/public
```
